# ReportForge PHP SDK

SDK de PHP para ReportForge, un motor de generación de documentos PDF con núcleo nativo en Rust.

```bash
composer require reportforge/reportforge
```

> **Este repositorio es un espejo de solo lectura.** Su contenido (código, binarios nativos y tags)
> lo genera automáticamente el workflow de release del proyecto principal en cada versión publicada.
> No envíes cambios ni pull requests aquí: cualquier modificación se sobrescribe en el siguiente release.

La documentación completa estará disponible en este README a partir del primer release.
